WHY THESE FILES (checked on KDP's help pages, 18 Oct 2026):
- KDP retired Kindle Kids' Book Creator in 2025 and stopped accepting MOBI files
  for fixed-layout books on 18 Mar 2025. Fixed-layout kids' books now go in as a
  KPF file made with Kindle Create, or as a fixed-layout EPUB.
- Kindle Create imports JPG, PNG or PDF pages (Comics option), in file-name order.
- eBook cover: JPEG or TIFF, RGB, under 50 MB, at least 625 x 1000 px, at most
  10,000 px per side. 1600 x 2560 is KDP's "ideal" for novels. A square cover is
  normal for a square picture book and meets every hard limit.
- Delivery fee on 70% royalty sales: US$0.15 per MB (A$0.15/MB, UK £0.10/MB).
  A 32-page picture book at print resolution is about 22 MB, which would eat most
  of the royalty. So the pages are 1600 x 1600 px (larger than a page shows on a
  Fire HD 10, with room to zoom), JPEG quality 80. The EPUB is 9.7 MB, about US$1.45 per sale.

STEP 1: MAKE THE MANUSCRIPT (pick ONE route)
================================================================================

ROUTE A (recommended, no extra app): upload the EPUB as it is.
- It's a fixed-layout EPUB 3 with Amazon's children's-book settings: 32 pages,
  1600 x 1600 px, left-to-right, page 1 on the right like the paperback, two-page
  spreads in landscape, and every page's story text as alt text for screen readers.
- Not tested in Kindle Previewer or epubcheck on this machine (no Java), so the
  check in Step 3 matters. If KDP's previewer shows blank, cropped or misordered
  pages, switch to route B.

ROUTE B (KDP's own tool): build a KPF file in Kindle Create.
1. Install Kindle Create from kdp.amazon.com/en_US/kindle-create (free).
2. Create New > Comics.
3. Reading direction: Left-to-Right. Facing Pages: ON.
4. Choose File > open the pages folder > select all 32 files (Ctrl+A) > Open.
   The names sort in order, so the pages import 1 to 32.
5. Check page 1 (title page) sits alone on the right. If Kindle Create pairs
   pages 1 and 2, select page 1 > Page Attributes > set it to Single.
   Every other page pairs as in the paperback: 2-3, 4-5 ... 30-31, 32 alone.
6. Table of contents (Page Attributes > Include in Table of Contents):
   page 1  "Who Took My Pouch?"
   page 3  "The Story"
   page 30 "True Facts from the Bush"
   page 32 "About the Author"
7. Skip Guided View. The pages are full-page art with large text.
8. File > Save Project (keep the .kcb file for later edits), then File > Export.
   Upload the .kpf file it makes. Kindle Create has no alt-text fields, so this
   route drops the alt text that route A carries.

AMAZON A+ CONTENT UPLOAD GUIDE (READY TO COPY & PASTE)
Book Title: Zoom Wonders
================================================================================

Images to upload: the 03_A_PLUS_CONTENT folder inside KDP_FINAL_UPLOAD.
They are 2x Amazon's minimum size (1940 x 600 and 1940 x 1200), so they stay sharp in
KDP's preview and on high-resolution screens. Don't upload the 970 px files in aplus\.

BEFORE YOU START: KDP doesn't publish module sizes. The sizes below are minimums from
third-party guides. If KDP rejects a larger file, use the 970 px version from aplus\.

STEPS
1. KDP > Marketing (top menu) > A+ Content card.
2. Choose the marketplace (start with Amazon.com) > Manage A+ Content.
3. Start creating A+ content. Name: "Zoom Wonders A+" (readers don't see it). Language: English.
4. Add the four modules in table order. Upload the image and paste the alt text.
   Leave text fields empty (the images carry their text). If KDP insists on a
   headline, use the one listed.

   MODULE 1: Standard Image & Light Text Overlay (970 x 300 minimum)
     Image:    aplus_1_banner_1940x600.jpg
     Alt text: Zoom Wonders coloring book by Flora Watt, cover and fire truck page
     Headline (only if required): Zoom Wonders

   MODULE 2: Standard Image Header With Text (970 x 600 minimum)
     Image:    aplus_2_features_1940x1200.jpg
     Alt text: Road train and submarine coloring pages with the book's features
     Headline (only if required): What's inside

   MODULE 3: Standard Image Header With Text (970 x 600 minimum)
     Image:    aplus_3_single_sided_1940x1200.jpg
     Alt text: 8.5 by 11 inch book with single-sided coloring pages
     Headline (only if required): Single-sided pages

   MODULE 4: Standard Image Header With Text (970 x 600 minimum)
     Image:    aplus_4_sample_grid_1940x1200.jpg
     Alt text: Six sample pages: monster truck, excavator, bullet train, sailboat, hot air balloon, Moon buggy
     Headline (only if required): Meet 50 amazing vehicles

5. Next: Apply ASINs > search the paperback ISBN (KDP > Bookshelf) > add the paperback.
6. Review & submit. Approved content appears within about eight business days.
7. Repeat for Amazon.com.au and every other store you sell in (A+ is set per
   marketplace). Copy the content across if KDP offers to.

If Amazon rejects an image, the likely cause is the inside-page samples. Note the
rejection message and rebuild that module.

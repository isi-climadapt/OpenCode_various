### Screen 2: Paperback Content

* **ISBN:** Select *"Get a free KDP ISBN"* (available because colouring books are NOT classified as low-content).
* **Publication Date:** Leave blank (will use current date).
* **Print Options:**
  * **Interior & paper type:** `Black & white interior with white paper`
  * **Trim Size:** `8.5 x 11 in (21.59 x 27.94 cm)`
  * **Bleed settings:** `No Bleed`
  * **Paperback cover finish:** `Matte` (recommended for Coco Wyo / cozy aesthetic) or `Glossy`
* **Manuscript:** Upload `AUSSIE_ANIMALS_INTERIOR_108P.pdf`
* **Book Cover:** Select *"Upload a cover you already have (print-ready PDF)"* → Upload `AUSSIE_ANIMALS_COVER_WRAP.pdf`
* **AI-Generated Content Disclosure:**
  * *"Did you use AI-based tools in creating texts, images, and/or translations in this book?"* → Select **"Yes"**
  * *Images:* Select **"Some with extensive editing"** (Interior linework created with AI-assistance, human curated, auto-contrasted, binarized, thickened, typeset, and laid out).
  * *Tools used:* `OpenArt, Nano Banana 2`
  * *Text:* Select **"No"** (All titles, captions, and front/back matter are written and typeset by humans).
